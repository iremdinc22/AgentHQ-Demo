# Dependency and artwork review

This inventory records declared licenses and notice files found in a clean installation on macOS arm64. It includes transitive dependencies. The production notice file preserves the license and notice texts found in the installed runtime package roots.

- `webgl-constants` omits the manifest license field. Its packaged LICENSE is MIT.
- Production JavaScript was attributed using a disposable source-map build. Of the five packages missing root notice files, only `@react-three/fiber` was emitted. The MIT notice from its [upstream v9.8.2 release](https://github.com/pmndrs/react-three-fiber/blob/v9.8.2/LICENSE) is included in the runtime notice file. `@mediapipe/tasks-vision`, `draco3d`, `maath`, and `stats-gl` remain installed dependencies, with no attributable modules in the built JavaScript and no corresponding shipped assets. Recheck if the production imports change.
- The runtime notice file includes the installed Tailwind CSS license for the distributed stylesheet. Source maps from the audit are outside the release output.
- No project-level license has been added. These notices apply to third-party components.
- The JPG character portraits come from the existing procedural models. The supplied custom WebP portraits are outside this candidate because the supplied archive documents asset mapping and intended UI use without establishing public redistribution rights or identifying the generation provider and applicable terms. Demo screenshots were captured in this project using fictional inputs. No original project screenshots were carried over.
- Only system font rendering is used. No font files are distributed.
